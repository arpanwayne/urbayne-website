# Urbayne Focus Flow

PROJECT: URBAYNE — PREMIUM SAAS WEBSITE REDESIGN & DEVELOPMENT

Act as a world-class UI/UX designer, creative director, senior frontend engineer, motion designer, and SaaS product marketing expert.

Your task is to build a complete, visually stunning, premium, modern, responsive, production-quality public website for Urbayne, using the existing software repository as the source of truth.

GitHub repository:
https://github.com/Wayneesolutions/urbayne

Existing website:
https://urbayne.wayneesolutions.com

1. FIRST: ANALYSE THE EXISTING PROJECT

Before writing or modifying code:

Inspect the entire repository, README, package.json files, apps, packages, existing frontend, backend, routes, authentication, API integrations, and documentation.

Identify the existing framework, styling system, reusable components, design conventions, and deployment configuration.

Understand what Urbayne actually does and which features are implemented versus planned.

Preserve the existing application, dashboard, API, authentication, database, environment variables, and role permissions.

Do not delete existing functionality or replace working application logic with mock implementations.

Build the public marketing website in the appropriate frontend application or an isolated, well-structured route/application based on the existing architecture.

Reuse existing dependencies whenever practical. Do not introduce unnecessary frameworks.

If a separate marketing frontend is necessary, keep it isolated from the existing dashboard and backend.

Do not stop after analysis. Once you understand the project, implement the complete website.

2. BRAND POSITIONING

Brand name: Urbayne

Positioning: A premium campaign management and field operations platform that helps organisations plan campaigns, coordinate teams, manage members, organise field activities, and monitor campaign progress through a unified digital system.

Target audiences:

Campaign owners and campaign managers

Organisations coordinating field teams

Regional and local campaign coordinators

Administrators managing multiple teams and users

Field workers who need simple, mobile-friendly workflows

The website should communicate trust, intelligence, organisation, operational clarity, and modern technology.

Use clear, professional English throughout the website.

Do not make unsupported claims about customers, revenue, adoption, security certifications, AI capabilities, or product performance.

3. VISUAL DESIGN DIRECTION

Create a sophisticated, premium SaaS aesthetic inspired by the quality of leading international technology brands, while keeping the visual identity original.

Visual characteristics:

Premium editorial typography

Spacious layouts with strong visual hierarchy

Large, impactful headlines

Cinematic photography featuring real human beings

Beautifully composed product dashboard mockups based on actual Urbayne functionality

Layered layouts and subtle 3D depth

Elegant gradients, soft lighting, realistic shadows, and refined borders

Carefully designed light and dark sections

Beautiful responsive navigation

Premium micro-interactions and smooth transitions

Suggested palette:

Deep midnight navy: #101827

Rich charcoal: #171C26

Electric blue accent: #5878FF

Soft lavender highlight: #A8AFFF

Clean off-white: #F7F8FC

White: #FFFFFF

Muted text: #667085

Treat these as the initial design direction. Inspect the existing Urbayne branding and preserve any established brand elements that should remain consistent.

Typography:

Use a modern font such as Inter, Manrope, or Plus Jakarta Sans.

Use bold, expressive headings and highly readable body text.

Keep font sizes, spacing, line heights, and weights consistent through a reusable design system.

Avoid generic template styling, excessive gradients, random colourful cards, oversized rounded rectangles everywhere, and repetitive layouts.

The final website must feel intentionally art-directed and professionally designed.

4. HUMAN PHOTOGRAPHY — ESSENTIAL

Use authentic, high-quality human photography throughout the website.

Photography should include:

Professional campaign coordinators working together

Diverse teams collaborating around a table

People coordinating field activities using mobile devices

Professionals reviewing plans and dashboards

Team leaders communicating with field staff

Realistic workplace and outdoor operational scenes

Use premium, natural-looking photography from reputable sources such as Unsplash or Pexels, or properly licensed equivalent sources.

Use actual image assets rather than emoji, cartoon illustrations, or generic AI-looking human characters.

Image requirements:

Large cinematic hero image or photo composition

Editorial image sections with thoughtful cropping

Subtle parallax where appropriate

Rounded or asymmetrically cropped image frames

Natural lighting, realistic skin tones, and professional photography

Responsive image sizing, lazy loading, and descriptive alt text

Never use the same photograph repeatedly across every section.

Ensure images load correctly and use stable image URLs or download approved assets into the project.

E. How Urbayne Works

02 — Coordinate Your Team
Manage members, responsibilities, and field operations through the platform.

03 — Monitor Progress
Review available activity and campaign information through the relevant dashboards.

Use a horizontal timeline on desktop and a vertical timeline on mobile.

Add scroll-triggered animations and a subtle animated connecting line.

Adapt the copy to the actual implemented workflows after repository inspection.

G. Role-Based Workflows

Explain the different user experiences supported by the existing system.

Superadmin:
Central administration and platform-level management, limited to verified permissions.

Admin:
Management of the resources, teams, and operations allowed by their assigned permissions.

Users and field workers:
Access to their permitted campaign workflows and relevant mobile-friendly functions.

Clearly distinguish campaign owners, administrators, and field workers according to the actual permission model.

Do not expose sensitive administrative functionality or imply that every role has identical access.

H. Mobile Experience

Create a dedicated mobile-first section showing how team members can access their permitted workflows on mobile devices.

Use realistic phone mockups containing accurate Urbayne interface designs.

Highlight ease of access, practical field workflows, and responsive interfaces.

K. Trust and Data Handling

Do not invent security certifications, encryption guarantees, compliance claims, or uptime commitments.

7. 3D EFFECTS AND PREMIUM ANIMATIONS

Implement tasteful, performance-conscious motion throughout the website.

Required effects:

Smooth page-load animations

Hero content reveal

Staggered entrance animations

Scroll-triggered section reveals

Subtle parallax on selected images

3D perspective on dashboard mockups

Gentle floating interface elements

Premium button hover states

Image zoom on hover

Card lift and depth effects

Animated navigation indicators

Smooth anchor scrolling

Animated process timelines

Elegant mobile menu transitions

Subtle background light or gradient movement

Use Framer Motion or the existing motion library if compatible with the project. Use CSS transforms for simple effects.

Animation guidelines:

Smooth, refined, and intentional

No excessive bouncing or distracting spinning elements

No constant movement that interferes with reading

Respect prefers-reduced-motion

Avoid scroll-jacking

Preserve accessibility

Maintain high performance on mobile devices

Every hover effect should feel polished and consistent.

10. RESPONSIVE DESIGN

Test and optimise the complete website for:

Mobile: 360px–430px

Tablet: 768px–1024px

Laptop: 1280px–1440px

Large desktop: 1600px and above

Ensure:

No horizontal overflow

No broken image crops

No overlapping text

No clipped navigation

No awkward spacing

No inaccessible buttons

No broken animations on touch devices

Design mobile layouts intentionally rather than shrinking desktop layouts.

11. SEO AND PERFORMANCE

Implement:

Unique title and meta description per page

Canonical URLs where appropriate

Open Graph metadata

Social sharing metadata

XML sitemap

robots.txt

Correct heading hierarchy

Descriptive image alt text

Appropriate structured data only when accurate

Internal links and breadcrumbs where useful

Optimised fonts and images

Lazy loading for below-the-fold images

Good Core Web Vitals practices

Do not add fabricated reviews, ratings, or organisation information to structured data.

Aim for excellent Lighthouse performance, accessibility, SEO, and best-practice scores without sacrificing visual quality.

Verify navigation and CTA destinations.

Do not stop after generating a homepage or a design mockup.

Build the complete, cohesive, production-oriented public website with all required pages and interactions.

The final result must look like a premium international SaaS company website, combining authentic human photography, elegant typography, cinematic layouts, realistic product mockups, tasteful 3D effects, polished hover interactions, and smooth animations.
